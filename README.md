<h1>Hi, I'm Soujanya S P 👋</h1>

I build AI systems that **do more than generate a response**.

My work focuses on turning LLMs into useful systems — ones that can **understand a task, retrieve the right information, use tools, coordinate with other agents, and carry a workflow through to completion**.

I'm particularly interested in **agentic AI, RAG, multi-agent systems, and the engineering behind reliable LLM applications**.

Most of the projects here start with a simple question:

“Can an AI system actually handle this end-to-end?”

I like figuring out the answer by building it — from the architecture and agent workflow to APIs, validation, integrations, and the details that make the system actually work.

📍 Bengaluru, India

🎯 Open to **AI Engineer / GenAI Engineer / LLM Engineer** opportunities.

## Projects

**CredAI** — Federated Multi-Agent Private Credit System

A multi-agent AI system for private credit workflows using LangGraph, RAG, FastAPI, ChromaDB, and Sarvam AI.

**Travel AI** — Autonomous Travel & Booking Assistant

An AI travel assistant that handles flight and hotel discovery, itinerary planning, and booking workflows using LangGraph, FastAPI, React, MCP, and external APIs.

**TicketMind** — AI Support Ticket Analytics

An AI-powered support-ticket analytics system that uses LLM-generated structured queries, Pydantic validation, deterministic execution, and SLA anomaly detection.
